#  PetLife — Adoção de Animais

Um projeto web desenvolvido para incentivar a adoção responsável de animais, aproximando pessoas que desejam adotar de cães e gatos que precisam de um novo lar.

O PetLife busca oferecer uma experiência simples, acolhedora e intuitiva, facilitando o acesso às informações sobre adoção e promovendo a conscientização sobre o cuidado com os animais.

##  Sobre o projeto

O PetLife é um site institucional de adoção de animais. Sua proposta é apresentar animais disponíveis para adoção, explicar as etapas do processo e permitir que os interessados enviem solicitações de adoção.

O projeto também conta com páginas informativas e canais de contato para aproximar a instituição dos visitantes.

##  Objetivos

- Incentivar a adoção responsável.
- Divulgar animais que estão procurando um lar.
- Facilitar o processo de solicitação de adoção.
- Compartilhar informações e orientações sobre cuidados com os animais.
- Proporcionar uma navegação acessível, organizada e agradável.

##  Funcionalidades

- **Página inicial:** apresentação do projeto, destaque principal e acesso às principais áreas do site.
- **Área de adoção:** exibição dos animais disponíveis para adoção.
- **Página individual do animal:** apresentação das informações do pet e formulário de solicitação de adoção.
- **Página de contato:** formulário para envio de mensagens e informações de contato.
- **Depoimentos:** relatos de pessoas que passaram pela experiência da adoção.
- **Notícias:** espaço destinado à divulgação de informações e conteúdos relacionados aos animais.
- **Navegação responsiva:** adaptação da interface para diferentes tamanhos de tela.

##  Como executar o projeto

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Verifique se os arquivos CSS, JavaScript e imagens estão nos caminhos corretos.
4. Abra o arquivo `index.html` no navegador.

Também é possível utilizar a extensão **Live Server** do Visual Studio Code para visualizar o projeto durante o desenvolvimento.
